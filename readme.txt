7. Добавляем другой алгоритм установки МО на складе 05 Павловский. Алгоритм называется Приоритетный склад по количеству или склад добора или склад хранения или оптовый склад.
7.1. Добавляем в работу программы возможность устанавливать разный срок дней запаса для Розничных магазинов и для Оптового склада(приоритетного по количеству).
7.1.1 По умолчанию срок устанавливается такой же как и для магазинов. В этом случае на Оптовый склад никаких МО добавляться не будет.
7.1.2. Если срок дней запаса Оптового склада > срока дней запаса для Розничных магазинов, то расчётное значение МО считается по следующему алгоритму.
Продажи всех Розничных магазинов делятся на количество дней анализа (по умолчанию 365) у умножаются на количество дней запаса для Оптового склада.
Далее из полученного значения вычитаются все расчётные значения Розничных магазинов и разница устанавливается на Оптовый склад.
Если разница будет меньше или равна 0, то устанавливается значения 0,96.
Разница меньше нуля может получиться из-за небольшой разницы в сроках, небольших продажах и при использовании кратности на подразделениях.
7.2. Так же оставляем возможность программе учитывать продажи самого Оптового склада для установки МО по желанию заказчика. Это задаётся при запуски программы.
В этом случае эти РЗ_МО будут добавляться к РЗ_МО полученных в п.7.1.
Так же, если и при добавлении этого значения РЗ_МО будет <= 0, то РЗ_МО устанавливаем  = 0,96.



Правила работы:

ТС выгружаем один МО необходимый нам с 05 Павловский и один Компания MaCar МО внешний.

5. Запускаемый файл должен находится в той же папке, что и папка "Исходные данные".
6. Запускаем программу "Соединение_файлов_универсальная.exe" и действуем согласно Алгоритм работы с интерфейсом программы.
7. Программа создаст файл с именем "Анализ МО по компании.xlsx"

Алгоритм работы с интерфейсом программы:
1. Задаём список складов в порядке убывания приоритета.
По умолчанию список складов расположен в следующем порядке: 01 Кирова, 02 Автолюбитель, 03 Интер, 04 Победа, 08 Центр, 09 Вокзалка.
Изменить порядок можно, вводя через запятую номера складов. Например: 8, 3, 2, 9, 1, 4. Если порядок менять не нужно, нажимаем Enter.
2. Задаём список складов, которые необходимо исключить из анализа (на этих складах МО меняться не будет).
По умолчанию список пуст. Если склады исключать не нужно, нажимаем Enter. При необходимости вводим номера складов через запятую. Например: 1, 4.
3. Выбираем режим работы с Кратностью и Комплектностью.
3.1. Чтобы не учитывать Кратность и Комплектность нажимаем Enter. В этом режиме Программа в независимости от установленной Кратности и
Комплектности в файле принимает значение Кратности и Комплектности равной 1.
3.2. Если необходимо учитывать Кратность и Комплектность, то нажимаем 1. 
Далее выбираем режим работы с Кратностью и Комплектностью.
3.2.1. Нажимаем 1 для выбора режима - Присваиваем значение кратности программой. Комплектность не учитываем.
В этом режиме программа запросит какое значения Кратности установить.
В независимости от значения Кратности в файле программа будет брать установленное значение Кратности из программы.
В независимости от значения Комплектности в файле программа будет брать значение равное 1.
3.2.2. Нажимаем 2 для выбора режима - Ограничиваем максимальное значение Кратности и Комплектности.
Далее программа запрашивает, какие максимальные значения Кратности и Комплектности установить.
В этом режиме учитывается значения Кратности и Комплектности полученные из файла, но не более чем установленные в
программе.
4. Вводим приоритетный склад из списка: 01 Кирова, 02 Автолюбитель, 03 Интер, 04 Победа, 08 Центр, 09 Вокзалка.
Если приоритетный склад устанавливать не требуется, то нажимаем Enter.
5. Программа запрашивает надо ли изменить значения по периодам анализа продаж и дней запаса. По умолчанию используются
значения (кол-во дней анализируемых продаж за 1 год = 365, кол-во дней анализируемых продаж за 3 мес = 91,
кол-во дней запаса = 91).
5.1. Если изменять не требуется, то нажимаем Enter.
5.2. Если требуется изменить, то вводим 1. Далее вводим новые значения кол-ва дней по каждому запросу отдельно:
дни анализа продаж за 1 год, дни анализа продаж за 3 мес, дни запаса для всех периодов.
6. Программа запрашивает, требуется ли учитывать продажи оптового склада. Если требуется, то вводим 1. Если не
требуется, то нажимаем Enter.
7. Программа запрашивает, требуется ли держать дополнительный запас на оптовом складе. Если не требуется, то нажимаем
Enter. Если требуется, то вводим 1. Далее:
7.1. Выбираем период анализа, на основании которого будет рассчитываться дополнительный запас на Оптовом складе:
1 - Длинный период (1 год), 2 - Короткий период (3 мес), 3 - Среднее значение. По умолчанию Длинный период.
7.2. Вводим минимальную сумму расчётных значений продаж, при котором необходимо держать дополнительный запас на
оптовом складе (по умолчанию 4). Значение не может быть меньше 1.
7.3. Вводим кол-во дней запаса для оптового склада. Оно не может быть меньше кол-ва дней запаса розничного склада.

Алгоритм расчёта МО в программе:
Кратко:
Т.к. алгоритм расчёта уже сложен для быстрого восприятия, то кратко без деталей он выглядит следующим образом.
Рассчитываем планируемые значения МО на Розничных складах = Продажи / дни анализа * дни запаса.
На Павловском устанавливаем значения на основании продаж по всем розничным складам.
В программе есть возможность указать приоритетный склад, выбрать режимы работы с Кратностью и Комплектностью,
указать склады, исключаемые из анализа, а так же возможность учитывать продажи оптового склада и добавлять его
расчётные значения к уже проставленным на основании Розничных продаж.
Детально:
1. Составляем список файлов, которые будут загружаться в программу. Если не требуется учитывать продажи оптового склада,
то программа исключает из списка файлов по продажам файлы, в наименовании которых содержится "техснаб" или "новотрейд"
в любом регистре.
1.1. Файлы продаж распределяются по трём спискам: за 2 года, за 1 год, за 3 мес. Считываем все файлы: по файлам продаж
создаём колонки "[Наименование склада] продажи за 1 год" и "[Наименование склада] продажи за 3 мес", по файлам МО -
колонки "[Наименование склада] МО".
2. Все колонки Кратность и Комплектность из файла "Комплектность, Кратность.xlsx" объединяем и помещаем в отдельную
таблицу.
2.1. Если используется установка Кратности программой, то устанавливаем в таблице Кратности это значение.
2.2. Если не используется установка Кратности, то ограничиваем значение кратности введённым максимальным значением Кратности.
По умолчанию 1.
2.3. Ограничиваем максимальное значение Комплектности. По умолчанию 1.
3. Считаем продажи по всем розничным складам (01 Кирова, 02 Автолюбитель, 03 Интер, 04 Победа, 08 Центр, 09 Вокзалка)
за период 2 года и записываем в колонку "Розн. продажи MaCar за 2 года".
4. Вычисляем расчётное значение МО по продажам подразделений за каждый период (1 год и 3 мес).
4.1. Суммируем все значения по складам отдельного подразделения (основной, возврат и т.п.), которые есть в файле.
4.2. Рассчитываем значения исходя из периода анализируемых продаж и периода запасов.
Делим продажи каждого магазина на количество анализируемых дней продаж (по умолчанию 365 за 1 год, 91 за 3 мес)
и умножаем на количество дней запаса (по умолчанию 91).
4.3. Обнуляем все рассчитанные МО меньше 0.
5. Суммируем продажи по розничным складам за 1 год и за 3 мес в колонки "Розн. продажи MaCar за 1 год" и
"Розн. продажи MaCar за 3 мес". При этом учитываются продажи только тех складов, где МО = 0 или МО >= 0.9.
6. По каждому складу рассчитываем:
6.1. "МО среднее значение" = (МО расчёт за 1 год + МО расчёт за 3 мес) / 2. Значение рассчитывается, если МО = 0 или
МО >= 0.9, дробная часть значения МО не входит в диапазон 0.24 - 0.29 и склад не в списке исключённых. В противном
случае значение = 0.
6.2. "Розн. MaCar МО расчёт за 1 год" = Розн. продажи MaCar за 1 год / дни анализа * дни запаса.
6.3. "Розн. MaCar МО расчёт за 3 мес" = Розн. продажи MaCar за 3 мес / дни анализа * дни запаса.
6.4. "Розн. MaCar МО среднее значение" = (МО расчёт за 1 год + МО расчёт за 3 мес) / 2. Значения меньше 0 обнуляются.
6.5. "Розн. MaCar МО расчёт (окр.)" = среднее значение, округлённое в большую сторону, с последующим приведением к
Кратности и Комплектности (см. п.7).
7. Приведение расчётных значений к Кратности и Комплектности:
7.1. Если 0 < значение <= Кратность, то устанавливаем значение Кратности.
7.2. Если 0 < значение <= (Комплектность с учётом Кратности = округление вверх (Комплектность / Кратность) * Кратность),
то устанавливаем значение Комплектности с учётом Кратности.
7.3. Все значения, которые больше Комплектности, приводим к значению кратному значению Кратности.
Т.е. значение делим на Кратность. Округляем до целого числа по математическим правилам. Умножаем на Кратность.
8. Далее корректируем расчётные значения МО на розничных складах согласно расчётному значению по компании
("Розн. MaCar МО расчёт (окр.)"):
8.1. Склады, которые указаны в списке исключения, а также склады, у которых дробная часть значения МО равна 0.24 - 0.29,
не участвуют в корректировке. На таких складах значение "... МО расчёт" остаётся равным текущему значению МО.
8.2. Склады сортируются по убыванию значения "МО среднее значение".
8.3. Определяем базовое значение для установки: value_default = Комплектность с учётом Кратности
(округление вверх (Комплектность / Кратность) * Кратность).
8.4. Определяем количество полных установок value_default: count_pass = "Розн. MaCar МО расчёт (окр.)" // value_default.
Остаток от деления распределяется по Кратности: count_pass_crat = ("Розн. MaCar МО расчёт (окр.)" % value_default) / Кратность.
8.5. Количество фактических установок ограничено складами, где расчётное значение позволяет установку:
для value_default - расчётное значение >= value_default, при добавлении Кратности - расчётное значение больше уже
установленного значения (для отслеживания установленных значений используются вспомогательные колонки "... МО расчёт тех").
8.6. Если на складе МО установлено 0 < МО < 0.9, то это значение не меняется ни в каком случае.
Даже если при расчете получается МО = 0,5. Это связано с тем, что сотрудники могут специально поставить какое-то
служебное значение, например для нового товара.
8.7. Распределение в зависимости от количества установок:
8.7.1. Если count_pass = 0:
- Если "Розн. продажи MaCar за 2 года" <= 0, то на всех участвующих складах устанавливаем 0.8.
- Если продажи были (за 2 года > 0), то устанавливаем value_default на складах, где текущее МО >= 1 (всего не более
чем на 2 склада). Если задан приоритетный склад и его МО >= 1, то он получает значение первым.
На складах, не получивших value_default: где МО >= 1 устанавливаем 0.93, на остальных 0.91.
8.7.2. Если count_pass = 1:
Если задан приоритетный склад и его МО = 0 или >= 0.9, то value_default устанавливается на нём. В противном случае -
на складе, где расчётное значение >= 1.
Остаток по Кратности (count_pass_crat) добавляется складам, где это позволяет расчётное значение.
На складах, не получивших значение: где МО >= 1 устанавливаем 0.93, где МО = 0 - 0.92.
8.7.3. Если count_pass = 2:
Если задан приоритетный склад и его МО = 0 или >= 0.9, то value_default устанавливается на нём, а так же на одном из
складов, где расчётное значение >= 1 и больше уже установленного (тех). В противном случае - на двух таких складах.
Далее остаток по Кратности и служебные значения как в п.8.7.2.
8.7.4. Если count_pass > 2:
value_default последовательно устанавливается на складах, где расчётное значение >= 1 и больше уже установленного (тех).
Далее остаток по Кратности и служебные значения как в п.8.7.2.
9. Устанавливаем МО в колонку "05 Павловский МО расчёт".
9.1. Если режим учёта продаж оптового склада выключен, то значение в этой колонке = 0.
9.2. Если задан дополнительный запас на оптовом складе (дни запаса оптового склада > дней запаса розничных):
9.2.1. Берём расчётное значение по розничным складам за выбранный период ("Розн. MaCar МО расчёт за 1 год",
"Розн. MaCar МО расчёт за 3 мес" или "Розн. MaCar МО среднее значение").
9.2.2. Если 0 < значение < 1, то принимаем его за 1, в противном случае округляем.
9.2.3. Если полученное значение >= минимальной суммы (по умолчанию 4), то
дополнительный запас = значение * (дни запаса оптового / дни запаса розничных) - значение.
9.2.4. Если дополнительный запас > 0, то добавляем его к значению "05 Павловский МО расчёт", в противном случае
оставляем значение как есть.
9.3. Приводим значение согласно Кратности (Комплектность на оптовом складе не используется):
9.3.1. Если значение = 0, то устанавливаем 0.96 (если текущее МО не в диапазоне 0 < МО < 0.9).
9.3.2. Если 0 < значение < Кратность, то устанавливаем значение Кратности.
9.3.3. В остальных случаях значение приводим к значению кратному Кратности (округляем по математическим правилам).
9.4. Если "Розн. MaCar МО расчёт (окр.)" = 0 и "Розн. продажи MaCar за 2 года" <= 0, то устанавливаем 0.8.
10. Устанавливаем значения в колонку "Компания MaCar МО расчёт".
10.1. Суммируем целые числа со всех колонок "... МО расчёт" участвующих складов, включая "05 Павловский МО расчёт",
и подставляем это значение в колонку "Компания MaCar МО расчёт".
10.2. Если "Розн. MaCar МО расчёт (окр.)" = 0:
- Если "Розн. продажи MaCar за 2 года" <= 0, то устанавливаем 0.8.
- Если продажи были, а сумма равна 0, то устанавливаем 0.91.
10.3. Если МО в колонке "Компания MaCar МО из 1С техническое" установлено 0 < МО < 0.9, то устанавливаем значение этого МО.
