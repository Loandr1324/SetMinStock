# SetMinStock — расчёт минимальных остатков (МО) по компании MaCar

Консольное приложение на Python для расчёта минимальных остатков (МО) по розничным складам и
оптовому складу компании. Собирает выгрузки продаж и МО из баз 1С (ШАВ, ШСВ, оптовая),
объединяет их и формирует итоговый файл **«Анализ МО по компании.xlsx»**.

## Технологии

- Python 3.11
- pandas, openpyxl, XlsxWriter, numpy
- PyInstaller (сборка исполняемого файла `.exe`)

## Как это работает

Программа — консольное приложение без графического интерфейса. Пользователь запускает
`main.py` (или готовый `.exe`), отвечает на вопросы в консоли, после чего программа:

1. Ищет файлы в папке **«Исходные данные»** (по ключевым словам в имени файла).
2. Загружает выгрузки продаж за периоды: **2 года**, **1 год**, **3 мес**, а также файлы с МО
   и файл «Комплектность, Кратность».
3. Рассчитывает плановые МО по каждому складу: `Продажи / дни анализа × дни запаса`
   (по умолчанию 365 дней анализа и 90 дней запаса).
4. Корректирует значения по правилам Кратности/Комплектности, учитывает приоритетный склад,
   продажи оптового склада 05 Павловский и дополнительные дни запаса на нём.
5. Сохраняет результат в файл **«Анализ МО по компании.xlsx»** в папке с программой.

## Установка и запуск

```powershell
# Создать виртуальное окружение (если ещё не создано)
python -m venv venv

# Активировать и установить зависимости
venv\Scripts\activate
pip install -r requirements.txt

# Запустить программу
venv\Scripts\python.exe main.py
```

Для запуска без установки Python можно использовать собранный
`Соединение_файлов_универсальная.exe` — он должен лежать в той же папке, что и папка
«Исходные данные».

## Правила работы с исходными данными

1. Все файлы, выгружаемые из базы, сохраняйте в папку **«Исходные данные»**.
2. В именах файлов по продажам должно быть слово **«продажи»**.
   Продажи выгружаются из баз ШАВ, ШСВ и оптовой (ТС или НТ).
3. В именах файлов по МО должно быть слово **«МО»**. МО выгружается из тех же трёх баз.
4. Рекомендуется пересохранять файлы из 1С под теми же именами, что и в папке
   «Исходные данные».
5. Программа создаёт файл «Анализ МО по компании.xlsx» в папке, где находится запускаемый
   файл.

## Работа с интерфейсом программы

При запуске программа последовательно запрашивает:

1. **Режим Кратности/Комплектности** — `Enter` (не учитывать), `1` (установить Кратность
   программой) или `2` (ограничить максимальные значения Кратности и Комплектности).
2. **Список складов в порядке приоритета** — по умолчанию: 01 Кирова, 02 Автолюбитель,
   03 Интер, 04 Победа, 08 Центр, 09 Вокзалка.
3. **Склады для исключения из анализа** — `Enter` (не исключать) или номера через запятую.
4. **Приоритетный склад** — номер склада или `Enter`, если приоритетный склад не нужен.
5. **Кол-во дней анализа продаж и дней запаса** — по умолчанию 365 и 90.
6. **Учёт продаж оптового склада** — `1`, если требуется учитывать.
7. **Дополнительный запас на оптовом складе** — `1`, если требуется; далее задаются период
   расчёта, минимальная сумма и кол-во дней запаса оптового склада.

## Алгоритм расчёта МО

Подробное описание алгоритма (пункты 7–12, включая установку МО на складе 05 Павловский и
по компании в целом) содержится в файле [readme.txt](readme.txt). Кратко:

- МО розничного склада = продажи склада / дни анализа × дни запаса (округляется вниз).
- Значения приводятся к Кратности и Комплектности, отрицательные обнуляются.
- МО на оптовом складе (05 Павловский) рассчитывается от суммы продаж всех розничных складов
  и может дополняться продажами самого оптового склада.
- «Компания MaCar МО расчёт» — сумма целых частей МО по всем складам.

## Сборка .exe

```powershell
venv\Scripts\pyinstaller --onefile main.py --exclude-module matplotlib ...
```

Готовый набор параметров сборки находится в `build5.bat`, конфигурация PyInstaller — в
`main.spec`. После сборки полученный `dist\main.exe` переименовывается в
`Соединение_файлов_универсальная.exe` и кладётся в корень проекта.
